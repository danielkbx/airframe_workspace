# Development Fixtures

This directory is the private workspace home for development and test inputs that do not belong in a public Swift package.

- `logs/`: representative private Blackbox logs and legacy Airframe documents. Its contents are intentionally ignored.
- Public, focused regression fixtures stay beside the Swift package tests that own them under `Airframe/Packages/`.

Do not put implementation documentation or research conclusions here. Durable factual research belongs in `knowledge/`.
