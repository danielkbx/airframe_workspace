# Overview Accessibility Checklist

- [x] Card headings are exposed once as headings.
- [x] Card and row actions use buttons with explicit labels and 44 × 44 pt minimum targets.
- [x] Missing values remove the complete row, avoiding meaningless placeholder announcements.
- [x] Loading rows retain a localized spoken loading state.
- [x] Key/value rows switch to a vertical layout at accessibility text sizes.
- [x] Equal-height grid cards remain top-aligned and grow with their tallest row peer.
- [x] Status values use text and symbols, not color alone.
- [ ] Manually verify VoiceOver reading order on iPhone and macOS.
- [ ] Manually verify keyboard focus order on macOS.
- [ ] Manually verify the largest accessibility text sizes with representative long values.
